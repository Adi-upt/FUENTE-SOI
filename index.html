El Problema vs. La Solución

El Problema: En soporte técnico, los procedimientos suelen estar dispersos en manuales extensos y guías de configuración. La diferencia entre el lenguaje del usuario y la terminología técnica dificulta localizar respuestas precisas cuando no hay personal especializado disponible de inmediato.

La Solución: Un prototipo web que separa dos funciones clave: RAG para recuperar fragmentos relevantes desde manuales PDF respondiendo con citas verificables (o abstención si no existe evidencia), y MCP para consultar herramientas operativas autorizadas de solo lectura.

Seguridad por diseño: Consultas públicas sin registro, administración documental protegida con Spring Security y BCrypt, y control estricto de herramientas para evitar ejecución de instrucciones no autorizadas desde archivos PDF.

Pilares del Diseño Tecnológico

01. Arquitectura Hexagonal

Backend en Spring Boot organizado en capas Domain, Application/Service e Infrastructure mediante puertos y adaptadores desacoplados.

02. Motor RAG (ProjectSevera)

Procesamiento documental con FastAPI y PyTorch en el nodo local MATTEOXPC (RTX 5070 Ti), sincronizando manuales PDF y metadata.json.

03. Interoperabilidad MCP

Cliente y servidor Model Context Protocol restringidos a una lista blanca de herramientas de consulta de solo lectura.

04. Red y Seguridad

Publicación HTTPS en Azure (MATTEO-01), enlace privado cifrado con Tailscale, reglas NSG/Firewall y defensa ante prompt injection.
