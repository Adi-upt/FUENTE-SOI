Aplicación web de asistencia documental basada en Generación Aumentada por Recuperación (RAG) y Model Context Protocol (MCP), desplegada entre Microsoft Azure (Windows Server 2022) y el nodo local ProjectSevera mediante Tailscale.

El Problema vs. La Solución

Problema: Las instrucciones de soporte técnico suelen distribuirse en múltiples manuales y guías de configuración. La brecha entre el lenguaje del usuario y la terminología técnica dificulta localizar respuestas precisas cuando no hay un especialista disponible de inmediato.

Solución: Una arquitectura web que combina RAG (para recuperar fragmentos de manuales PDF y responder con referencias verificables o abstenerse ante falta de evidencia) y MCP (para consultar herramientas operativas de solo lectura), protegiendo la gestión documental mediante Spring Security y BCrypt.

Backend Hexagonal (Azure)

Desplegado en la VM MATTEO-01 (Windows Server 2022) con Java / Spring Boot, estructurado en capas Domain, Application e Infrastructure, con acceso público de consulta y administración protegida.

Motor IA y RAG (Nodo Local)

Ejecutado en el equipo local MATTEOXPC (RTX 5070 Ti) mediante FastAPI, PyTorch y ProjectSevera, manteniendo el índice vectorial sincronizado con los PDF y metadata.json.

MCP y Conectividad Segura

Interoperabilidad mediante Model Context Protocol limitada a herramientas autorizadas de solo lectura y comunicación privada cifrada entre Azure y la PC local con Tailscale.
